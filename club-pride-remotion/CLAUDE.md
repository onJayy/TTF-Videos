# Working on this project (for Claude Code)

This is a Remotion (React + TypeScript) project with two 9:16 compositions: `SlotSpin` and `MapRoulette`.
Both share the same back half: `RapidRound` → `EndCard` (the score screen `Result` exists but is switched off; `T.result = 0`).

## Commands
- `npm run studio` – preview. `npm run typecheck` – type check (run after edits).
- `npx remotion still <Comp> out/x.jpg --frame=N` – check a single frame quickly.
- `npx remotion render <Comp> out/x.mp4 --props='{"clubId":"<id>"}'` – render.

## Rules
- All animation must be driven by `useCurrentFrame()` (no CSS transitions, no Math.random – use `random(seed)` from remotion).
- Pacing lives in `src/timing.ts`; brand colours/fonts in `src/brand.ts`; club data in `src/data/`.
- A new club round = either a compressed recording in `public/rounds/` + an entry in `src/data/rounds.ts` with each answer's `reveal` second and `correct`, or generated questions via `gen(question, options, answerIndex)` (rendered by `AppScreen`).
- Only write questions whose answers are well-established facts; double-check anything recent.
- Keep content inside the 9:16 safe area: nothing important above y≈260 (Reels header) or below y≈1560 (caption/username), and keep x>960 clear between y≈1000–1560 (like/comment buttons).
- Never draw or download official club crests (trademarks). The slot reel uses `ClubBadge`: a user-supplied file in `public/crests/<id>.png` if present, else `ClubShield` (club colours + 3-letter code). The map uses `StadiumBadge`.
- Sounds are generated by `tools/make_sfx.py`; don't add copyrighted music.
- Brand: greens `#84C27A` / `#3F9E49` / `#1E3D1B`, berry `#A83462`, font Poppins (bundled in `public/fonts`).
